# 女装标题详情页命名

根据商品图片与已确认资料，生成中外文合一产品名、淘宝商品标题和六栏目详情页文案。

**技能调用名：`$womenswear-copy`**

[查看完整技能](SKILL.md) · [命名规则](references/naming.md) · [标题规则](references/titles.md) · [详情页规则](references/detail-v2.md)

## 可以做什么

| 模式 | 默认输出 |
| --- | --- |
| 产品命名 | 5 个中外文合一候选，每个名称独立一行 |
| 淘宝标题 | 3 条标题，采用同一个选定名称 |
| 详情页 | 1 套六栏目文案 |
| 全套文案 | 命名、标题、详情页分别输出 |
| 局部改写 | 只改指定内容，保留其他已确认部分 |

## 如何使用

已安装本技能的 Codex 中，附上商品图片并输入：

> 使用 $womenswear-copy，根据这些图片生成全套文案。  
> 商品主体：短外套  
> 确认面料：填写已确认资料，没有则省略  
> 已用名称：填写需要避开的名字，没有则省略

也可以只做一个部分：

> 使用 $womenswear-copy，只给这款连衣裙起 5 个名字，中外文合一。

> 使用 $womenswear-copy，用我选定的名称生成 3 条淘宝标题。

> 使用 $womenswear-copy，只写六栏目详情页，依据图片，不确定的材质不要编写。

仓库用于保存技能文件。换电脑后，需要把整个技能目录安装到当地 Codex 技能目录；仅打开 GitHub 页面不会自动安装。安装时保留 SKILL.md、references 和 agents 的相对位置。

## 成品格式

### 产品命名

外文与中文组合成一个完整名称，不拆成两栏，不默认附释义或分析。

外文使用准确的 1–2 个真实词；不同商品突出不同特征，避免重复套名。

### 淘宝标题

```text
寄信丨完整中外文名称 相关商品关键词
```

品牌前缀默认沿用「寄信丨」，可以按用户要求替换。名称之后使用空格，后续关键词连贯组合；除品牌分隔符外不添加标点。

关键词按商品灵活组织，不固定词序，不为了搜索而写入未经确认的材质或功能。

### 六栏目详情页

```text
01 DESIGN INSPIRATION
【设计主线 商品表达】
按语义分成短行正文

02 SILHOUETTE
【版型特点 比例观感】
按语义分成短行正文

03 DETAILS
【具体细节 设计作用】
按语义分成短行正文
可根据实物增加不同的细节小节

04 WEARABILITY
【穿着搭配 适用场景】
按语义分成短行正文

05 FABRIC
【材质或可见肌理 质感表现】
按语义分成短行正文

06 COLOR
【颜色特点 视觉气质】
按语义分成短行正文
```

整体采用成熟、克制的商品编辑文风，解释具体设计及其作用，避免空泛抒情与反复堆叠同一卖点。

## 不满意时怎么改

**当次修改直接在对话中提出。** 指明修改范围、希望的方向和需要保留的内容。

> 名字太柔美，重新给 5 个更成熟、有辨识度的名字。标题和详情页先不改。

> 只重写 01 设计灵感和 06 颜色。少一点诗意，多写产品本身，其余保留。

> 第二个名字保留，三条标题都改用它，详情页不要变。

**长期偏好确认后再保存到技能。**

> 把这条加入技能：以后命名避开云、雾、月等高频意象。

只有明确要求保存的规则才作为长期更新；一次修改不自动成为所有商品的要求。本地技能与 GitHub 是两份文件，修改后若需要同步，请明确说「更新本地技能并同步到这个仓库」。

## 图片与资料的使用边界

- 先看全部商品图，再识别品类、轮廓、颜色、纹理与可见细节。
- 图片无法确认面料成分、保暖性、弹性、尺寸等，不把推测写成事实。
- 参考商品的材质不直接迁移到新商品，搭配配件也不视作随货附赠。
- 名称避开当前对话及提供的历史名单，无法读取完整历史时不承诺全店永久无重复。
- 技能生成文案，不自动发布商品或修改店铺。
